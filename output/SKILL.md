# Oracle Browser Skill

Use the Python CLI:

```bash
ORACLE_CLI="/home/user01/project/oracle_new/.venv/bin/oracle-plus"
```

## Standard Flow

```bash
"$ORACLE_CLI" --engine browser --browser-model-strategy ignore --wait --slug "example" --write-output /tmp/oracle_final_capture.md -p "Prompt"
```

## Prompt Input

Use `-p` for short inline prompts.

Use `--file` for actual file attachments, source files, review targets, or context globs.

Use `--prompt-file` only when the prompt body is long, multiline, contains code fences, or is generated by another tool and you want to load it from a local text file.

```bash
cat > /tmp/oracle_prompt.md <<'EOF'
Write the final answer.

Requirements:
- Preserve the existing Oracle Browser Skill contract.
- Include concrete implementation steps.
- Do not invent unsupported behavior.
EOF

"$ORACLE_CLI"   --engine browser   --browser-model-strategy ignore   --wait   --slug "example-file-prompt"   --write-output /tmp/oracle_final_capture.md   --prompt-file /tmp/oracle_prompt.md
```

`--prompt-file` reads the prompt text from the given local file path and sends that file content as the Oracle prompt.

### `--prompt-file` constraints

* Use either `-p "Prompt"` or `--prompt-file /path/to/prompt.md`, not both.
* The `--prompt-file` path must point to an existing, readable local file.
* Use UTF-8 plain text or Markdown prompt files. Non-UTF-8 files are rejected.
* Do not use `--prompt-file` as a replacement for upstream `--file` when Oracle should inspect attachments, source files, review targets, or context globs.
* If Oracle needs to inspect a file, attach it with `--file` or include the full file contents directly in the prompt.
* A path mentioned inside prompt text is only prose unless the file is also supplied via `--file`.
* If Oracle needs multiple files for context, attach them with `--file` or include every required file's contents directly in the prompt instead of sending only local paths.
* Keep `--write-output` separate from `--prompt-file`: `--prompt-file` is prompt input, `--write-output` is final capture output.
* For generated prompt files, write the file completely before invoking `oracle-plus`.
* Quote the `--prompt-file` path if it may contain spaces.
* `--prompt-file` is convenience sugar over `-p`; it is not the primary file-attachment contract.
* Very large prompt files may still hit OS argument length limits because the wrapper forwards prompt text as CLI arguments.
* Browser runs can stay silent for up to 30 minutes before the wrapper times out for inactivity.

## Contract

- Auto-select ports `9473-9479`.
- Keep `~/.cache/oracle-plus/ports/*.lock`.
- Keep `~/.cache/oracle-plus/runs/<slug>.meta`.
- Keep Node `@steipete/oracle` as the browser automation layer.
- Control commands bypass browser auto-selection.
- `--prompt-file` is a prompt-input option equivalent to supplying prompt text via `-p`, except the prompt is read from a local file.
